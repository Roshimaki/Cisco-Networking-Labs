# Cisco Networking Labs

This repository contains my Cisco Packet Tracer networking labs focused on practical network configuration and troubleshooting.

## Topics Covered
- VLAN Configuration
- Inter-VLAN Routing
- Subnetting
- DHCP
- Multilayer Switching
- Static Routing
- Router-to-Router Communication
- Cisco IOS CLI

## Lab Projects

### 1. Enterprise Network Design Lab
Simulated an enterprise-style network with departmental VLAN segmentation, DHCP services, and multilayer switch connectivity.

### 2. InterVLAN Routing and Subnetting
Configured VLANs, native VLANs, subnetting, and inter-VLAN communication using a multilayer switch.

### 3. Router-to-Router Network Lab
Designed a routed network topology connecting multiple LANs through routers for inter-network communication.

### 4. VLAN and DHCP Lab
Configured VLAN segmentation and DHCP services for automatic IP assignment within isolated network segments.

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI
